# L.A.V.A. Home

Live Acoustic & Seismic Volcano Archive - Home 화면(세계 지도, VAAC 말풍선, Volcano & Alerts 패널, 미니맵).

이 저장소는 **Vercel에 배포하는 웹 앱만** 담고 있습니다.

- 앱: [`web/`](web/) (Next.js 16 + React 19 + react-leaflet). Vercel의 Root Directory를 `web`으로 지정합니다.
- 실행·환경 변수·배포 방법: [`web/README.md`](web/README.md)

변환 전 원본 Python(Dash) 앱은 배포에 필요하지 않아 저장소에서 뺐지만 Git 이력에 남아 있습니다.
`git checkout 60a30d4 -- original_python` 으로 꺼낼 수 있습니다.
